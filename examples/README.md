# Synthetic assessment cases

Each Markdown file is a fictional task. Its matching JSON file is a curated
illustrative assessment, not a recorded model response or empirical outcome.
Tests validate these contracts and preserve their distinctions; they do not claim
to make model reasoning deterministic.

- `ready`: a 40-module cohesive portability migration. Size alone is no split reason.
- `clarify`: session continuity needs owner intent; locating adapters is research.
- `split`: separately approved login and reporting outcomes have independent verdicts.
- `hold`: the required signed interface and fixtures have not arrived.
